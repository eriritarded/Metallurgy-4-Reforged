# ProjectE EMC adaptation

Implemented source2026-10-16. All three base adapters compile in `evidence/configured-packs-compile-checkpoint.json`; native ProjectE data is supplied only for the two reviewed targets. ProjectE decoding, mapping results, transmutation and interaction with changed pack recipes have not been run. No game/tests or user configuration/installation changes occur.

The original `IntegrationProjectE` table is imported at pinned Metallurgy1.4.1 revision `ef94cb94cfc08ccebe8a0df307ce6b390dcd4704`. `content/projecte-values.json` records the exact Java file SHA256,49 base metal values, seven extra items and original equipment multipliers. The supplied source/JAR remains untouched.

`tools/generate_projecte_resources.py` writes the reviewed native `pe_custom_conversions` format for Forge1.20.1 and NeoForge1.21.1. Exact dependency sources, codecs, examples and blob IDs are in `projecte-api-baseline.json`. The optional built-in pack is registered only when `projecte` is loaded and `GeneralConfig.projectEIntegration` is true. It uses ProjectE's own data loader, with no obsolete API calls, reflection or packaged foreign classes. Its resource wrapper filters disabled acquisition categories from fixed values and tool conversions before decoding. No unavailable output can be acquired through a deliberately disabled category in this pack.

Each supported target has367 fixed assignments: ingot/dust at the49 original metal base values, nugget at integer base/9, storage block at base×9,41 armor sets at helmet/chest/legs/boots multipliers5/8/7/4, plus the seven extras. Extras are iron dust256, gold dust2048, potash128, potash fertilizer256, phosphorus128, bitumen256 and tar128. Tool values use195 fixed-from-conversion entries, five tools for39 materials. Metal counts are axe3, hoe2, pickaxe3, shovel1 and sword2, plus two sticks for every tool as in the source. ProjectE supplies its current stick EMC during mapping; the port avoids reading the proxy before native mapping has finished.

The source's hardcoded metal values and integer nugget truncation are retained; no new economy/balance claim is made. Pack authors changing crafting, alloys or EMC should also review these data entries. Higher-priority packs can replace the same conversion resource. New modular/spartan items are not silently assigned an invented base EMC by this integration; ProjectE may derive them through its own enabled mappers.

The current official ProjectE branches reviewed include `mc1.20.x` (`68fbb2dea0cf8a6394fa6c7c084063046d94cee5`) and `mc1.21.1` (`f432b0c66837759fb0731c9144dc53176b949c5d`). No official26.1.2 branch/API was found in the branch inventory on this review date. No26.1.2 format or dependency claim is fabricated; the base26 Metallurgy port remains independent of ProjectE.
