# Original project credits

Metallurgy4: Reforged by Davoleo, Matpac and contributors; based on Metallurgy4 by ShadowClaimer and its team. Original project: https://github.com/Davoleo/Metallurgy-4-Reforged, GPLv3. Source revision and supplied artifact identities are recorded in docs/source-baseline.json.

Metallurgy Chests by KreloX: https://github.com/KreloX/metallurgychests, GPLv3. The five chest tiers are integrated into Metallurgy by this requested port. Original artwork and attribution are retained.

The optional Forge Spartan Weaponry integration retains90 unchanged sprite files from the original dependency, Spartan Weaponry1.5.3 by ObliviousSpartan, with weapon ideas/art by xwerffx. Source: https://github.com/ObliviousSpartan/SpartanWeaponry. Apache License2.0 is retained at `META-INF/licenses/SpartanWeaponry-Apache-2.0.txt`; source archive and per-file hashes are recorded in `docs/spartan-art-baseline.json`. These sprites use new native3.2.1 model/pose definitions under Metallurgy's namespace. Native model sources/revisions are recorded in `content/spartan-native-models.json`. No Spartan implementation classes are bundled.

This port is not an official release by the original authors. The upstream README expressly states its authors' plans against future-version ports; this adaptation does not imply their endorsement. The user requested a public upstream fork on 2026-10-23. Source publication is separate from binary releases, installation and gameplay validation; current state is recorded in docs/GITHUB-FORK.md and the dated release/install records.

The Hephaestus trait adapter recovers Metallurgy Reforged and SlimeKnights TConstruct2 trait behavior through new native Hephaestus callbacks. Hephaestus/Hephaestus Tools by titammods supply the optional APIs and runtime; no dependency implementation classes or artwork are bundled. Reviewed source/dependency identities and deliberate behavior translations are recorded in docs/HEPHAESTUS-TRAITS.md and docs/hephaestus-traits-source-review.json.
